# 閲覧者による最小確認票

このタスクのブラウザはサイト安全ポリシーによりアクセス拒否。以下は**未実行の手順**であり、許可された通常の閲覧環境の利用者へ渡す。制限回避用コード、別ブラウザへの切替、Cookie抽出、HAR共有は不要。

## 標本と操作

公開・無料の通常動画2件を画面内の仮称A/Bで記録する。追加の大量検索をしない。タイトル・ID・検索語を記録票へ書かない。既存の検索/タグ画面を使い、並び順・表示設定を変更しない。既にリスト／タイルが見られる場合だけ比較し、片方しかない場合はもう片方を未確認にする。広告カードは既に表示されている場合だけ観測する。

1. 操作前に、プレビュー有効/無効、ログイン有無、一般/プレミアム等を値でなく区分として記す。ブラウザ版・OSの種類を控える。ログインや有料権限の変更を行わない。
2. Aへ短く入り離脱（200ms未満を目安）。次にAへ留まり、hover開始・loading表示・初映像・コメント初表示を区別して経過秒を測る。
3. 最大35秒程度の1回で、映像の開始位置・30秒前後の停止・短動画の自然終了・ループ有無を確認する。再hoverで先頭へ戻るか記す。
4. A→Bへゆっくり移動して同時再生の見え方、さらに短い移動を1回だけ確認する。移動中の一時的な重なりと継続同時再生を分ける。
5. 一覧のスクロールで画面外へ移し、戻す。次に別の無関係なタブの内容を記録せずタブ非表示→復帰だけ確認する。音声を出す必要はない。
6. 通常のページ内遷移→戻るを1回。並び替えqueryの直接送信は設定保存の可能性があるため使わない。追加通信数、先頭再開、古いcanvas残留を確認する。

音量ボタンのclick/keyboard、ミュート解除、別カードへの保持、reload後の保持は別枠。この保存公式版には計測・再生数更新の呼出経路があるため、現在の「副作用を伴う操作をしない」という範囲では未実施とする。必要になった段階で閲覧者が許容する範囲を明示してから、低い音量で1回だけ解除→元へ戻す。ブラウザ設定・サイト音量設定を変更して自動再生制限を回避しない。

## 開発者ツールで見る場合

NetworkのPreserve logや全文exportは不要。通常のページ通信のうち、1回のhoverで増えたものだけをDevToolsで目視し、以下の**名称・型・件数・一致判定**を転記する。スクリーンショットにも署名や本文が写らないようにする。生HARは渡さない。

| 観測 | 記録する値 | 記録しない値 |
|---|---|---|
| preview | method、正規化path、status、header名、schema、件数 | ID、query実値、Cookie、本文 |
| HLS権限 | 同一動画/キー一致boolean、status、expireTime項目有無、期限までの相対時間 | key、署名URL、Set-Cookie値 |
| manifest/segment | 要求数、bytes合計、CORS成功/失敗、停止後増加有無、initiatorの種類 | 配信URL、path内token、動画本体 |
| comment | thread数、comments総数、params一致、現在時刻との関係、描画数の観測 | 本文、thread ID、userId、キー |
| DOM | data-nameの階層、video propertiesのmute/volume/currentTime/paused、canvas有無 | outerHTML全文、srcのblob値 |
| event | pointer/keyboard別、ボタンがリンクへ遷移しないか、所有component名 | React state全体、認証/視聴者データ |

blob生成元はNetwork initiatorと保存コードのHLS attach→MediaSourceの接続で確認する。URL文字列の一致だけで「再生元API」としない。DevToolsで調べられない項目は未確認のまま残す。自動操作を通すためにfetch/MediaSourceを差し替えたり、認証を代理転送したりしない。

| 条件 | A通常 | B通常 | 広告 | 根拠 |
